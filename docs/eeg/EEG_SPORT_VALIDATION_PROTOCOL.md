# EEG Sport Validation Protocol

## Purpose

Define a repeatable method to evaluate EEG-based training feedback in sports contexts.

## Intended Use

- reaction-time drills
- cognitive-motor training sessions
- focus/load trend tracking across sessions

## Not Intended Use

- diagnostic medical decisions
- emergency/acute clinical triage
- unsupported claims without measured evidence

## Study Design Template

- cohort definition
- inclusion/exclusion criteria
- session protocol and duration
- signal quality criteria
- artifact handling criteria
- outcome metrics and statistical method

## Core Metrics (Template)

- signal quality pass rate
- artifact rejection rate
- session completion rate
- response-time trend delta
- intra-session stability metrics

## Data Quality Gates

A session is valid only if:

- minimum channel quality threshold met
- artifact ratio below configured threshold
- sampling and timing checks pass
- metadata complete (session type, athlete id pseudonym, timestamp)

## Reporting Structure

For each pilot:

- protocol version
- population size
- number of valid sessions
- observed metric deltas
- limitations and confounders
- reproducibility notes

## Ethics and Privacy

- consent required before data collection
- pseudonymization by default
- retention and deletion follow policy docs

## Claim Readiness Levels

- Level 0: concept only, no pilot evidence
- Level 1: internal pilot evidence
- Level 2: external pilot with reproducible method
- Level 3: multi-site validated evidence

Public claims should include current level.
