# EEG Public Claims Boundaries

## Purpose

Set safe communication boundaries for public statements about EEG capabilities.

## Allowed Claim Types

- capability claims (what system does)
- workflow claims (how coaches can use outputs)
- measured pilot observations with context and limitations

## Restricted Claim Types

- guaranteed performance outcomes
- guaranteed injury reduction
- clinical/medical efficacy claims without validated evidence
- broad generalization beyond tested population

## Required Claim Format

Each external claim should include:

- context (sport/use case)
- evidence level (see protocol levels)
- limitation statement
- non-diagnostic disclaimer where appropriate

## Safe Language Examples

Use:

- can support
- may help monitor
- pilot observations suggest

Avoid:

- proves
- guarantees
- eliminates risk

## Mandatory Disclosures

- pilot/internal vs external validation status
- sample limitations
- confounding factors
- environment constraints (hardware/setup quality)

## Review Process for Claims

1. Draft claim text.
2. Check against this policy.
3. Validate against latest evidence pack.
4. Approve by product + technical owner.

## Escalation

If a claim is uncertain or evidence is weak, downgrade language or block publication.
