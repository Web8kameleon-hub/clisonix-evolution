# 2026-10-14 — Fix: align remaining Python 3.13 references to 3.14

## Issue

Six configuration files had drifted to Python 3.13 while the rest of
the repository's CI/Dockerfiles had already moved to 3.14: this created
an inconsistent build/runtime version across services and workflows.

## Documentation

Confirmed via repo-wide search that 3.14 is the dominant, intentional
convention (13 of 15 `python-version:` entries across
`.github/workflows/*.yml`, plus `translation_node`'s
`Dockerfile.translation` and most service Dockerfiles). Updated the six
stragglers to match:

- `ocean-core/Dockerfile`: `FROM python:3.13-slim` → `python:3.14-slim`
- `.github/workflows/clisonix_security_cicd.yml`: `python-version: '3.13'` → `'3.14'`
- `.github/workflows/single-branch-pr-governance.yml`: `python-version: "3.13"` → `"3.14"`
- `scripts/hetzner/deploy_ocean_swarm.sh`: one-shot `python:3.13-bookworm` health-probe container → `3.14-bookworm`
- `scripts/hetzner/deploy_clx_runtime_swarm.sh`: two probe containers → `3.14-bookworm`
- `scripts/hetzner/deploy_jona_swarm.sh`: one probe container → `3.14-bookworm`
- `scripts/hetzner/deploy_web_swarm.sh`: one probe container → `3.14-bookworm`

The `hetzner/deploy_*_swarm.sh` instances are disposable `docker run`
containers used only to `curl`/`urllib.request` a deployed service's
health endpoint after rollout; they are not application runtime images,
so bumping their base image has no behavioral effect on the probe
logic.

## Tests

- `bash -n` on all four modified shell scripts: no syntax errors.
- `python -c "import yaml; yaml.safe_load(...)"` on both modified
  workflow YAML files: parses cleanly.

## Edge cases

- Left the one pre-existing `python-version: '3.11'` entry in
  `ci-green.yml`'s `Zero Regression Gate` job untouched -- that is a
  separate, deliberate pin unrelated to the 3.13→3.14 drift this change
  addresses, and changing it was out of scope.
- Left all `.md` documentation files mentioning 3.13 (deployment guides,
  historical summaries) untouched -- those are point-in-time narrative
  records, not active configuration.

## Benchmark

Not applicable -- version-string alignment only, no logic change.

## Rollback

Seven independent single-line-per-file changes; `git revert` restores
3.13 everywhere with no cascading effect, since no code in this change
depends on a specific Python 3.14 feature.
