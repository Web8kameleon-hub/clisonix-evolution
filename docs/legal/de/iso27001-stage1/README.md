# ISO 27001 Stage-1 Package (Germany/EU)

This folder contains practical Stage-1 preparation artifacts.

## Contents
1. ISO27001_SCOPE_AND_BOUNDARY.md
2. ISO27001_STATEMENT_OF_APPLICABILITY_TEMPLATE.csv
3. ISO27001_RISK_REGISTER_TEMPLATE.csv
4. ISO27001_EVIDENCE_CHECKLIST.csv

## Usage
1. Fill scope and boundary first.
2. Populate risk register with owners and deadlines.
3. Map controls in SoA with implementation status.
4. Attach objective evidence and schedule internal audit.
