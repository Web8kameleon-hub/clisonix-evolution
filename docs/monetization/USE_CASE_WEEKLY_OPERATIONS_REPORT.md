# Weekly Operations Report - Automated

## One-Line Promise

Replace 5 hours of reporting with 1 command.

## Who This Is For

Consulting firms that prepare weekly client reporting packs.

## Problem

Teams lose hours every week combining data, formatting slides, and producing client-ready files.

## Clisonix Flow

1. Upload or connect sources (sales + operations files/URLs).
2. Run one command: `Generate weekly ops report`.
3. Download output pack.

## Inputs

- Sales KPI table (CSV/XLSX)
- Operations summary (CSV/XLSX)
- Optional notes/document links

## Outputs

- Excel: structured KPI workbook
- PDF: executive summary for client delivery

## Demo Script (20-30 seconds)

1. Open `Web Reader`.
2. Enter command: `Generate weekly ops report`.
3. Select output: `PDF`.
4. Click generate and download.

## Data Trust

Your data never leaves your system (BYOC mode).
