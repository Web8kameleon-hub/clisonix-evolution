# Support

## Contact

For support requests, use the official contact listed in README.md.

- Email: clisonix@pm.me
- Website: https://clisonix.com

## Response Expectations

- Critical production incidents: best effort same day
- Standard technical questions: 1-3 business days
- Documentation requests: 2-5 business days

## Include in Your Request

- affected service(s)
- exact error message
- timestamps and timezone
- environment (local/staging/production)
- recent changes (deploy/config)

## Security Issues

Do not open public issues for vulnerabilities.
Use the process in SECURITY_CONTACT.md.
