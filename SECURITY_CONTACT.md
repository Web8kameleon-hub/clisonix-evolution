# Security Contact

## Private Reporting

Report security vulnerabilities privately.

Primary contact: clisonix@pm.me

## What to Include

- vulnerability type
- affected components
- reproduction steps
- impact assessment
- suggested mitigation (if available)

## Coordinated Disclosure

- We acknowledge receipt as soon as possible.
- We investigate and classify severity.
- We coordinate remediation and disclosure timing.

## Do Not

- disclose exploitable details publicly before remediation
- include real secrets in reports
- perform destructive testing on production systems
